# NutriCraft
A dietary-compliant Android meal planner built with MIT App Inventor, featuring a reverse recipe engine and clinical health filters.
NutriCraft Meal Planner
NutriCraft is an Android application designed to generate dietary-compliant meal schedules directly from available pantry ingredients. Built with a focus on medical and dietary compliance, the app prioritizes users managing clinical conditions such as diabetes by automatically balancing glycemic loads and macronutrients.

Key Features
Reverse Recipe Engine: Generates daily meal schedules strictly from user-inputted pantry ingredients to minimize food waste and extra shopping trips.

Time-Bound Scheduling: Calculates precise portion scaling and overlapping cooking steps for batch meal prepping over set timeframes.

Clinical Dietary Filters: Utilizes dedicated algorithmic profiles to ensure all generated meal plans comply with strict diabetes management requirements.

Installation Instructions
Locate the NutriCraft_Complete.apk file in this repository and download it to your Android device.

Open your device's security settings and enable Allow installation from unknown sources (or allow your browser to install unknown apps).

Tap the downloaded .apk file to install and launch the application.

Development and Editing
This project is built using MIT App Inventor. To view the block logic or modify the application:

Download the NutriCraft_Complete.aia source file from this repository.

Log into MIT App Inventor in your web browser.

Navigate to Projects > Import project (.aia) from my computer and select the downloaded file.

Modify the visual layout in the Designer view or adjust the application logic in the Blocks editor.
